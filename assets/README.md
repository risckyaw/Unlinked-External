# Unlinked External - Runtime Assets

This directory contains runtime assets that are packaged beside the executable:

- **`Unlinked.webp`**: Brand banner and application visuals.
- **`fonts/`**: UI typography suites (`Inter`, `Poppins`, `Nunito`).
- **`icons/`**: Bundled glyph icon packs (`fontawesome/`).
- **`themes/`**: Customizable UI color theme presets (`unlinked.theme`, `example.theme`).
